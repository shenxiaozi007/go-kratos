# 前端开发文档：萌宠之家

本文档约定萌宠之家前端（front-pet-app）的页面、路由、组件、设计规范及与后端 API 的对接方式。

---

## 1. 技术选型与目录

- **选型**：纯静态 + 原生 JS，或 React/Vue 单页；与 code.html 原型一致可采用 React + Tailwind。
- **目录建议**（front-pet-app）：
  - `index.html` 或 SPA 入口
  - `css/common.css`：公共 Tailwind 与自定义（玻璃效果、主题色）
  - `js/api.js`：封装 fetch，baseURL + Authorization: Bearer &lt;token&gt;
  - `js/auth.js`：登录/注册、localStorage 存 token、跳转
  - 各页或各路由对应组件（见下）

---

## 2. 设计规范（与原型一致）

- **字体**：Plus Jakarta Sans（Google Fonts）。
- **主色**：primary `#ef3957`；浅色背景 `#f8f6f6`，深色背景 `#221013`。
- **圆角**：默认 1rem，lg 2rem，xl 3rem。
- **组件**：玻璃效果 `backdrop-filter: blur(10px)`；图标可用 Material Symbols Outlined。
- **布局**：移动端优先，最大宽度约 448px（max-w-md）居中，底部 Tab 固定。

## 4. 全局组件

- **BottomNav**：4 Tab（首页、社交、互动、我的），当前页高亮 primary 色。
- **Header**：标题、返回按钮、右侧图标（设置/通知等）；各页按需传入 title、showBack、rightIcon、onRightClick。
- **SignInModal**：签到弹窗，连续天数、7 日日历、「立即签到领奖励」→ POST /api/v1/checkin。

---

## 5. 页面与 API 对接

### 5.1 首页 (/)

- **数据**：GET `/api/v1/pet/me`；404 表示无宠物，引导领养。
- **状态**：未登录 → 引导登录；已登录无宠物 → 领养入口；有宠物 → 展示卡片与成长数据、快捷入口。

### 5.2 互动页 (/interaction)

- **进入**：GET `/api/v1/pet/me`，渲染名字、心情、亲密度、饱食度/心情值/清洁度（若接口返回）、宠物图。
- **互动**：点击工具栏或热点 → POST `/api/v1/pet/interact`，Body `{ "action": "STROKE" }`（或 TEASE/TREAT/BATH）；用返回的 Pet 更新亲密度条与心情等。

### 5.3 我的 (/profile)

- **数据**：GET `/api/v1/auth/profile` 判断登录；GET `/api/v1/pet/me` 或宠物列表用于「我的宠物」。
- **登出**：清除 localStorage token，跳转首页或登录态。

### 5.4 商店与背包

- **商店**：GET `/api/v1/shop/items` 列表；购买 POST `/api/v1/shop/buy`，Body item_id, quantity。
- **背包**：GET `/api/v1/inventory`；使用道具 POST `/api/v1/inventory/use`，Body item_id, pet_id?。

### 5.5 领养与换装

- **品种列表**：GET `/api/v1/breeds?species=CAT` 或 DOG；品种详情 GET `/api/v1/breeds/:id`；领养 POST `/api/v1/pet`。
- **换装**：GET `/api/v1/pet/:id/appearance` 当前装扮；保存 PUT `/api/v1/pet/:id/appearance`。

---

## 6. 配置与 CORS

- **API Base URL**：`window.APP_CONFIG?.apiBaseUrl || 'http://localhost:8000'`，便于本地与部署切换。
- **Token**：登录成功后存 localStorage（如 key `pet_app_token`），请求头统一带 `Authorization: Bearer ${token}`；登出删除。
- 后端已配置 CORS（realworld internal/server/http.go），前端只需在 fetch 中带上述 Header。

---

## 7. 依赖与运行

- 安装最新依赖：在 front-pet-app 目录下执行 `npm install`（若使用 npm）；使用 React 则需安装 react、react-dom、react-router-dom 等。
- 开发时可将 API 指向本地 realworld 服务（如 http://localhost:8000），并确保已登录获取 token。

更多接口细节见 [02-后端开发文档.md](02-后端开发文档.md)。

## 8. 当前已实现（front-pet-app）

- **技术栈**：Vite 5 + React 18 + React Router 6 + Tailwind CSS 3。
- **API 层**：`src/api/api.js`（request + Bearer token）、`auth.js`、`pet.js`、`checkin.js`、`user.js`、`shop.js`、`breed.js`、`friend.js`、`achievement.js`。
- **认证**：`AuthContext` 管理登录态，Token 存 `localStorage.pet_app_token`；登录/注册页 `/login`、`/login?register=1`。
- **全局组件**：`BottomNav`（首页/社交/互动/我的）、`Header`（标题、返回、右侧图标）、`SignInModal`（签到弹窗、7 日日历、立即签到）。
- **页面与路由**：首页 `/`、互动 `/interaction`、社交 `/social`、我的 `/profile`、商店 `/shop`、背包 `/inventory`、领养 `/adoption`、品种详情 `/breed-detail/:id`、编辑资料 `/edit-profile`、购买成功 `/purchase-success`、成就 `/achievements`、换装 `/dressup`、排行榜 `/ranking`、好友申请 `/requests`。
- **设计**：Plus Jakarta Sans、主色 `#ef3957`、玻璃效果、最大宽度 448px、底部 Tab 导航。
- **开发**：`cd realworld/front-pet-app && npm install && npm run dev`（端口 5174，API 代理到 8000）。详见 [front-pet-app/README.md](../../front-pet-app/README.md)。
