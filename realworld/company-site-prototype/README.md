# 公司官网

单页静态官网，可直接部署到任意静态托管（如 GitHub Pages、Vercel、OSS 等）。

## 如何本地查看

- 在浏览器中直接打开 `index.html`，或
- 本地起静态服务：`npx serve .` 或 `python3 -m http.server 8080` 后访问

## 内容结构

- **首屏**：品牌口号与主视觉
- **产品与服务**：三个能力模块（产品设计、技术实现、持续运营）
- **关于我们**：团队与理念简述
- **联系我们**：表单（提交后打开本地邮件客户端）+ 直链邮箱

## 技术说明

- 纯静态：`index.html` + `favicon.svg`，无构建步骤
- 深色主题，金色点缀；字体：Cormorant Garamond（标题）+ Outfit（正文）
- 响应式布局；联系表单通过 `mailto:` 唤起邮件客户端，后续可改为后端接口

## 部署

将本目录整体上传至静态托管根路径，或配置构建产物为本目录即可。
